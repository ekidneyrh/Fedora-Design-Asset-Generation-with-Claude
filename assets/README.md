# assets/

This directory would be a copy of the [Fedora Design Team's assets](https://forge.fedoraproject.org/design/assets). Claude would read from here when it needs a logo, mascot, wallpaper or past design to build into a new graphic.

**The assets themselves are not committed to this repository.**

## Name your files descriptively

Claude picks assets based on their filenames. Vague names produce bad choices so make sure to be descriptive. An example:

```
mascots/Beefy/
├── beefy-angry.svg
├── beefy-confident.svg
├── beefy-excited.svg
├── beefy-sleepy.svg
├── beefy-waving.svg
└── ...
```

The same applies to wallpapers (`F45-wallpaper-final-night.svg` is better than `wallpaper2.svg`) and logo variants (`fedora_white-horizontal.svg` is better than `logo-v3.svg`). 

## Licensing

Fedora design assets are subject to the [Fedora brand guidelines](https://docs.fedoraproject.org/en-US/project/brand/). Review them before using Fedora logos or branding elements in anything you publish.
