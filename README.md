# Fedora Design Asset Generation with Claude

A template project directory for generating brand-compliant SVG design assets for the Fedora Project using the [Claude Code CLI](https://code.claude.com/docs/en/quickstart).

This repository is the companion to the blog post **[Fedora Design Asset Generation with Claude](https://emmakidney.com/2026/11/13/fedora-design-asset-generation-with-claude/)**, which explains the reasoning behind the workflow and walks through a real case study.

> **This is a template, not an asset library.** The `assets/` directory is left empty. The Fedora design assets live on the [Fedora Design Team's forge](https://forge.fedoraproject.org/design/assets). 

---

## Repository structure

```
/
├── CLAUDE.md          # Brand rules Claude reads on every request
├── assets/            # There source assets would be 
└── outputs/           # Where generated files are stored
```
